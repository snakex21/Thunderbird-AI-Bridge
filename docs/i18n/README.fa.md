# Thunderbird AI Bridge

[English / فهرست کامل زبان‌ها](../../README.md)

## چیست؟

Thunderbird AI Bridge یک پل محلی میان Thunderbird و عامل‌های هوش مصنوعی، ابزارهای CLI، اسکریپت‌ها و برنامه‌های سفارشی است. افزونه عملیات صندوق پستی را انجام می‌دهد و یک برنامه محلی از طریق یک پروتکل کوچک HTTP روی `127.0.0.1` با آن ارتباط می‌گیرد.

**SuperCLI الزامی نیست.** نخستین host برای SuperCLI ساخته شد، اما هر برنامه‌ای که پروتکل توضیح‌داده‌شده در [docs/PROTOCOL.md](../PROTOCOL.md) را پیاده‌سازی کند می‌تواند از افزونه استفاده کند.

## قابلیت‌ها

- فهرست حساب‌ها و پوشه‌ها،
- ساخت، تغییر نام و حذف پوشه‌ها،
- جستجو بر اساس فرستنده، گیرنده/نشانی، موضوع، متن و تاریخ،
- خواندن پیام بدون تغییر عمدی وضعیت خوانده‌شدن،
- خواندن پیام‌های بلند به‌صورت بخش‌بندی‌شده،
- فهرست و انتقال پیوست‌ها برای مدل‌های vision یا پردازش اسناد،
- جابه‌جایی پیام، انتقال به Trash و بازیابی،
- حذف دائمی با بررسی IMAP،
- Empty Trash/EXPUNGE بومی Thunderbird،
- وارد کردن پیام Outlook `.msg` پس از تبدیل به `.eml`،
- عملیات گروهی در دسته‌های محدود با continuation token.

## امنیت

عملیات حساس محافظت بیشتری دارند. اقدامات مخرب به `confirm: true` نیاز دارند، حذف دائمی فقط از Trash انجام می‌شود و پوشه‌های سیستم/root محافظت می‌شوند. برنامه host نیز باید پیش از اقدامات مخرب تأیید روشن کاربر را دریافت کند.

این پل برای استفاده محلی طراحی شده است. host را مستقیماً در LAN یا اینترنت در دسترس قرار ندهید.

## ساخت

Thunderbird 128 یا جدیدتر لازم است.

```bash
python scripts/build_xpi.py
npm test
```

فایل XPI در `dist/thunderbird-ai-bridge.xpi` ساخته می‌شود و می‌توان آن را به‌صورت دستی از مدیر افزونه‌های Thunderbird نصب کرد.

وضعیت: آزمایشی (`0.9.21`). پروتکل ممکن است پیش از `1.0` تغییر کند.
