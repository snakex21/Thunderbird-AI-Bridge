# Thunderbird AI Bridge

[English / قائمة اللغات الكاملة](../../README.md)

## ما هو؟

Thunderbird AI Bridge هو جسر محلي بين Thunderbird ووكلاء الذكاء الاصطناعي وأدوات سطر الأوامر والبرامج النصية والتطبيقات المخصصة. تنفذ الإضافة عمليات البريد، بينما يتواصل معها برنامج محلي عبر بروتوكول HTTP صغير على `127.0.0.1`.

**لا يتطلب SuperCLI.** تم إنشاء أول host لـ SuperCLI، لكن يمكن لأي برنامج استخدام الإضافة إذا نفذ البروتوكول الموضح في [docs/PROTOCOL.md](../PROTOCOL.md).

## الميزات

- عرض الحسابات والمجلدات،
- إنشاء المجلدات وإعادة تسميتها وحذفها،
- البحث حسب المرسل أو المستلم/العنوان أو الموضوع أو النص أو التاريخ،
- قراءة الرسائل دون تغيير حالة القراءة عمداً،
- قراءة الرسائل الطويلة على أجزاء،
- عرض المرفقات ونقلها لنماذج الرؤية أو معالجة المستندات،
- نقل الرسائل إلى مجلدات أخرى أو سلة المهملات واستعادتها،
- حذف دائم مع التحقق عبر IMAP،
- استخدام Empty Trash/EXPUNGE الأصلي في Thunderbird،
- استيراد رسائل Outlook `.msg` بعد تحويلها إلى `.eml`،
- عمليات جماعية على دفعات محدودة مع رموز continuation.

## الأمان

العمليات الحساسة لها طبقات حماية إضافية. تتطلب الإجراءات التدميرية `confirm: true`، ويقتصر الحذف الدائم على سلة المهملات، كما تتم حماية مجلدات النظام/root. ويجب على برنامج host أيضاً طلب موافقة واضحة من المستخدم.

تم تصميم الجسر للعمل محلياً. لا تعرض الـ host مباشرة على الشبكة المحلية أو الإنترنت.

## البناء

يتطلب Thunderbird 128 أو أحدث.

```bash
python scripts/build_xpi.py
npm test
```

يتم إنشاء ملف XPI في `dist/thunderbird-ai-bridge.xpi` ويمكن تثبيته يدوياً من مدير إضافات Thunderbird.

الحالة: تجريبية (`0.9.21`). قد يتغير البروتوكول قبل `1.0`.

الترخيص MIT. مشروع مستقل وغير تابع لـ Mozilla أو Thunderbird.
