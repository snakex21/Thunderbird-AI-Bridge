# Thunderbird AI Bridge

[English / รายการภาษาทั้งหมด](../../README.md)

## คืออะไร?

Thunderbird AI Bridge คือสะพานเชื่อมแบบ local ระหว่าง Thunderbird กับ AI agent, เครื่องมือ CLI, script และแอปพลิเคชันที่พัฒนาขึ้นเอง ส่วนขยายจะทำงานกับกล่องจดหมาย และโปรแกรมในเครื่องจะสื่อสารผ่าน HTTP protocol ขนาดเล็กบน `127.0.0.1`

**ไม่จำเป็นต้องใช้ SuperCLI** host ตัวแรกถูกสร้างสำหรับ SuperCLI แต่โปรแกรมใดก็สามารถใช้ส่วนขยายนี้ได้ หากรองรับ protocol ที่อธิบายไว้ใน [docs/PROTOCOL.md](../PROTOCOL.md)

## ความสามารถ

- แสดงบัญชีและโฟลเดอร์,
- สร้าง เปลี่ยนชื่อ และลบโฟลเดอร์,
- ค้นหาจากผู้ส่ง ผู้รับ/ที่อยู่ หัวเรื่อง ข้อความ และวันที่,
- อ่านข้อความโดยไม่ตั้งใจเปลี่ยนสถานะอ่านแล้ว/ยังไม่อ่าน,
- อ่านข้อความยาวเป็นช่วง ๆ,
- แสดงและส่งไฟล์แนบไปยัง vision model หรือระบบประมวลผลเอกสาร,
- ย้ายข้อความ ส่งไป Trash และกู้คืน,
- ลบถาวรพร้อมการตรวจสอบ IMAP,
- ใช้ Empty Trash/EXPUNGE แบบ native ของ Thunderbird,
- import Outlook `.msg` หลังแปลงเป็น `.eml`,
- ทำงานจำนวนมากเป็น batch จำกัดพร้อม continuation token

## ความปลอดภัย

การทำงานที่มีความเสี่ยงมีการป้องกันเพิ่มเติม การลบหรือแก้ไขข้อมูลที่สำคัญต้องใช้ `confirm: true` การลบถาวรจำกัดไว้ใน Trash และโฟลเดอร์ system/root ได้รับการป้องกัน host ควรขอคำยืนยันจากผู้ใช้ก่อนทำงานที่ทำลายข้อมูลด้วย

Bridge ถูกออกแบบสำหรับการใช้งานในเครื่อง อย่าเปิด host โดยตรงให้ LAN หรือ Internet เข้าถึง

## Build

ต้องใช้ Thunderbird 128 หรือใหม่กว่า

```bash
python scripts/build_xpi.py
npm test
```

XPI จะถูกสร้างที่ `dist/thunderbird-ai-bridge.xpi` และติดตั้งด้วยตนเองผ่านตัวจัดการ Add-ons ของ Thunderbird ได้

สถานะ: experimental (`0.9.21`) protocol อาจเปลี่ยนก่อน `1.0`
