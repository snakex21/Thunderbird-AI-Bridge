# Thunderbird AI Bridge

[English / повний список мов](../../README.md)

## Що це?

Thunderbird AI Bridge — локальний міст між Thunderbird та AI-агентами, CLI-інструментами, скриптами й власними застосунками. Розширення виконує операції з поштою, а локальна програма спілкується з ним через невеликий HTTP-протокол на `127.0.0.1`.

**SuperCLI не потрібен.** Перший host було створено для SuperCLI, але будь-яка програма може використовувати розширення, якщо реалізує протокол з [docs/PROTOCOL.md](../PROTOCOL.md).

## Можливості

- список облікових записів і папок,
- створення, перейменування та видалення папок,
- пошук за відправником, одержувачем/адресою, темою, текстом і датою,
- читання листів без навмисної зміни стану прочитано/непрочитано,
- читання довгих повідомлень частинами,
- список і передавання вкладень для vision-моделей або обробки документів,
- переміщення листів, Кошик і відновлення,
- остаточне видалення з перевіркою IMAP,
- нативні Empty Trash/EXPUNGE Thunderbird,
- імпорт Outlook `.msg` після перетворення на `.eml`,
- масові операції обмеженими пакетами з токенами продовження.

## Безпека

Чутливі операції мають додатковий захист. Руйнівні дії потребують `confirm: true`, остаточне видалення дозволене лише з Кошика, а системні/root-папки захищені. Host також має запитувати чітке підтвердження користувача.

Bridge призначений для локальної роботи. Не відкривайте host безпосередньо в LAN або Інтернет.

## Збірка

Потрібен Thunderbird 128 або новіший.

```bash
python scripts/build_xpi.py
npm test
```

XPI створюється у `dist/thunderbird-ai-bridge.xpi` і може бути встановлений вручну через менеджер додатків Thunderbird.

Статус: експериментальний (`0.9.18`). Протокол може змінюватися до `1.0`.
