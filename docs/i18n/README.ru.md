# Thunderbird AI Bridge

[English / полный список языков](../../README.md)

## Что это?

Thunderbird AI Bridge — локальный мост между Thunderbird и ИИ-агентами, CLI-инструментами, скриптами и собственными приложениями. Расширение выполняет операции с почтой, а локальная программа общается с ним через небольшой HTTP-протокол на `127.0.0.1`.

**SuperCLI не требуется.** Первый host был создан для SuperCLI, но любое приложение может использовать расширение, если реализует протокол из [docs/PROTOCOL.md](../PROTOCOL.md).

## Возможности

- список учетных записей и папок,
- создание, переименование и удаление папок,
- поиск по отправителю, получателю/адресу, теме, тексту и дате,
- чтение писем без намеренного изменения статуса прочитано/не прочитано,
- постраничное чтение длинных сообщений,
- список и передача вложений для vision-моделей или обработки документов,
- перемещение писем, отправка в Корзину и восстановление,
- постоянное удаление с проверкой IMAP,
- нативные Empty Trash/EXPUNGE Thunderbird,
- импорт Outlook `.msg` после преобразования в `.eml`,
- массовые операции ограниченными пакетами с continuation token.

## Безопасность

Чувствительные операции имеют дополнительные ограничения. Разрушающие действия требуют `confirm: true`, постоянное удаление разрешено только из Корзины, а системные/root-папки защищены. Host также должен запрашивать явное подтверждение пользователя.

Bridge предназначен для локальной работы. Не публикуйте host напрямую в LAN или Интернет.

## Сборка

Требуется Thunderbird 128 или новее.

```bash
python scripts/build_xpi.py
npm test
```

XPI создается в `dist/thunderbird-ai-bridge.xpi` и может быть установлен вручную через менеджер дополнений Thunderbird.

Статус: экспериментальный (`0.9.21`). Протокол может измениться до `1.0`.
