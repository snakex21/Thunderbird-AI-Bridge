# Thunderbird AI Bridge

[English / सभी भाषाओं की सूची](../../README.md)

## यह क्या है?

Thunderbird AI Bridge, Thunderbird और AI एजेंटों, CLI टूल, स्क्रिप्ट तथा कस्टम ऐप्लिकेशन के बीच एक स्थानीय ब्रिज है। एक्सटेंशन मेलबॉक्स पर काम करता है और एक स्थानीय प्रोग्राम `127.0.0.1` पर छोटे HTTP प्रोटोकॉल के माध्यम से उससे बात करता है।

**SuperCLI आवश्यक नहीं है।** पहला host SuperCLI के लिए बनाया गया था, लेकिन [docs/PROTOCOL.md](../PROTOCOL.md) में दिया गया प्रोटोकॉल लागू करने वाला कोई भी प्रोग्राम इस एक्सटेंशन का उपयोग कर सकता है।

## सुविधाएँ

- खाते और फ़ोल्डर सूचीबद्ध करना,
- फ़ोल्डर बनाना, नाम बदलना और हटाना,
- प्रेषक, प्राप्तकर्ता/पता, विषय, पूर्ण पाठ और तारीख से खोज,
- जानबूझकर read/unread स्थिति बदले बिना संदेश पढ़ना,
- लंबे संदेशों को भागों में पढ़ना,
- vision मॉडल या दस्तावेज़ प्रोसेसिंग के लिए अटैचमेंट सूचीबद्ध और ट्रांसफ़र करना,
- संदेशों को स्थानांतरित करना, Trash में भेजना और वापस लाना,
- IMAP सत्यापन के साथ स्थायी हटाना,
- Thunderbird का native Empty Trash/EXPUNGE,
- `.eml` में बदले Outlook `.msg` संदेश आयात करना,
- continuation token के साथ सीमित बैच ऑपरेशन।

## सुरक्षा

संवेदनशील कार्रवाइयों पर अतिरिक्त सुरक्षा है। विनाशकारी कार्यों के लिए `confirm: true` आवश्यक है, स्थायी हटाना केवल Trash से किया जाता है और system/root फ़ोल्डर सुरक्षित हैं। host को भी उपयोगकर्ता से स्पष्ट अनुमति लेनी चाहिए।

ब्रिज स्थानीय उपयोग के लिए बनाया गया है। host को सीधे LAN या इंटरनेट पर उजागर न करें।

## बिल्ड

Thunderbird 128 या नया संस्करण आवश्यक है।

```bash
python scripts/build_xpi.py
npm test
```

XPI `dist/thunderbird-ai-bridge.xpi` में बनता है और Thunderbird के Add-ons Manager से मैन्युअल रूप से इंस्टॉल किया जा सकता है।

स्थिति: प्रयोगात्मक (`0.9.21`)। `1.0` से पहले प्रोटोकॉल बदल सकता है।

MIT लाइसेंस। Mozilla या Thunderbird से संबद्ध आधिकारिक परियोजना नहीं है।
