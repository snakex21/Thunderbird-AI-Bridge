# Thunderbird AI Bridge

[English / πλήρης λίστα γλωσσών](../../README.md)

## Τι είναι;

Το Thunderbird AI Bridge είναι μια τοπική γέφυρα μεταξύ του Thunderbird και AI agents, εργαλείων CLI, scripts και προσαρμοσμένων εφαρμογών. Η επέκταση εκτελεί λειτουργίες στο γραμματοκιβώτιο και ένα τοπικό πρόγραμμα επικοινωνεί μαζί της μέσω ενός μικρού HTTP πρωτοκόλλου στο `127.0.0.1`.

**Το SuperCLI δεν είναι απαραίτητο.** Ο πρώτος host δημιουργήθηκε για το SuperCLI, αλλά οποιοδήποτε πρόγραμμα μπορεί να χρησιμοποιήσει την επέκταση εφόσον υλοποιεί το πρωτόκολλο που περιγράφεται στο [docs/PROTOCOL.md](../PROTOCOL.md).

## Δυνατότητες

- λίστα λογαριασμών και φακέλων,
- δημιουργία, μετονομασία και διαγραφή φακέλων,
- αναζήτηση κατά αποστολέα, παραλήπτη/διεύθυνση, θέμα, πλήρες κείμενο και ημερομηνία,
- ανάγνωση μηνυμάτων χωρίς σκόπιμη αλλαγή της κατάστασης αναγνωσμένο/μη αναγνωσμένο,
- ανάγνωση μεγάλων μηνυμάτων σε τμήματα,
- λίστα και μεταφορά συνημμένων για vision models ή επεξεργασία εγγράφων,
- μετακίνηση μηνυμάτων, αποστολή στον Κάδο και επαναφορά,
- μόνιμη διαγραφή με επαλήθευση IMAP,
- εγγενές Empty Trash/EXPUNGE του Thunderbird,
- εισαγωγή Outlook `.msg` μετά από μετατροπή σε `.eml`,
- μαζικές λειτουργίες σε περιορισμένα batches με continuation token.

## Ασφάλεια

Οι ευαίσθητες λειτουργίες έχουν επιπλέον προστασία. Οι καταστροφικές ενέργειες απαιτούν `confirm: true`, η μόνιμη διαγραφή περιορίζεται στον Κάδο και οι φάκελοι system/root προστατεύονται. Ο host πρέπει επίσης να ζητά σαφή επιβεβαίωση από τον χρήστη.

Η γέφυρα έχει σχεδιαστεί για τοπική χρήση. Μην εκθέτετε τον host απευθείας σε LAN ή Internet.

## Build

Απαιτείται Thunderbird 128 ή νεότερο.

```bash
python scripts/build_xpi.py
npm test
```

Το XPI δημιουργείται στο `dist/thunderbird-ai-bridge.xpi` και μπορεί να εγκατασταθεί χειροκίνητα από τον διαχειριστή πρόσθετων του Thunderbird.

Κατάσταση: experimental (`0.9.21`). Το πρωτόκολλο μπορεί να αλλάξει πριν το `1.0`.
