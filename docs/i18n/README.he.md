# Thunderbird AI Bridge

[English / רשימת השפות המלאה](../../README.md)

## מה זה?

Thunderbird AI Bridge הוא גשר מקומי בין Thunderbird לבין סוכני AI, כלי CLI, סקריפטים ויישומים מותאמים. ההרחבה מבצעת פעולות בתיבת הדואר, ותוכנית מקומית מתקשרת איתה באמצעות פרוטוקול HTTP קטן על `127.0.0.1`.

**SuperCLI אינו נדרש.** ה-host הראשון נבנה עבור SuperCLI, אבל כל תוכנה יכולה להשתמש בהרחבה אם היא מממשת את הפרוטוקול המתואר ב-[docs/PROTOCOL.md](../PROTOCOL.md).

## יכולות

- הצגת חשבונות ותיקיות,
- יצירה, שינוי שם ומחיקה של תיקיות,
- חיפוש לפי שולח, נמען/כתובת, נושא, טקסט מלא ותאריך,
- קריאת הודעות בלי לשנות בכוונה את מצב נקרא/לא נקרא,
- קריאת הודעות ארוכות בחלקים,
- הצגת והעברת קבצים מצורפים למודלי vision או לעיבוד מסמכים,
- העברת הודעות, שליחה ל-Trash ושחזור,
- מחיקה קבועה עם אימות IMAP,
- Empty Trash/EXPUNGE מובנה של Thunderbird,
- ייבוא Outlook `.msg` לאחר המרה ל-`.eml`,
- פעולות מרובות באצוות מוגבלות עם continuation token.

## אבטחה

לפעולות רגישות יש הגנות נוספות. פעולות הרסניות דורשות `confirm: true`, מחיקה קבועה מוגבלת ל-Trash ותיקיות system/root מוגנות. גם ה-host צריך לבקש אישור ברור מהמשתמש לפני פעולה הרסנית.

הגשר מיועד לשימוש מקומי. אין לחשוף את ה-host ישירות לרשת LAN או לאינטרנט.

## Build

נדרש Thunderbird 128 או חדש יותר.

```bash
python scripts/build_xpi.py
npm test
```

קובץ XPI נוצר ב-`dist/thunderbird-ai-bridge.xpi` וניתן להתקין אותו ידנית דרך מנהל התוספים של Thunderbird.

מצב: ניסיוני (`0.9.18`). הפרוטוקול עשוי להשתנות לפני `1.0`.
